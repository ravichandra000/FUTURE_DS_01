
#### 📊 Super Store Sales Dashboard & Forecast (Power BI)

## 📌 Project Overview

This project presents an interactive **Super Store Sales Dashboard** built using **Power BI** as part of my **Future Interns Data Science & Analytics Internship**.

The dashboard provides a clear and insightful analysis of sales performance, customer segments, shipping modes, and regional trends. Additionally, it includes a **sales forecasting module** to analyze future patterns based on historical data.

---

## 🎯 Objectives

* Analyze overall sales performance
* Identify top-performing categories and sub-categories
* Understand regional and state-wise sales distribution
* Track monthly and yearly sales trends
* Visualize shipping mode contributions
* Implement sales forecasting for better decision-making

---

## 📊 Dashboard Features

### 🔹 Key Performance Indicators (KPIs)

* **Total Sales:** 2.26M
* **Total Quantity Sold:** 21.97K
* **Total Profit:** 678K
* **Average Delivery Time:** 39K

---

### 🔹 Visual Insights

* 📈 **Sales Trend Analysis** (Month & Year wise)
* 🗺️ **Sales by State** (Map Visualization)
* 🧩 **Sales by Segment** (Consumer, Corporate, Home Office)
* 📦 **Sales by Category & Sub-Category**
* 🚚 **Sales by Shipping Mode**
* 🌍 **Region Filters** (Central, East, South, West)

---

### 🔹 Forecasting Dashboard

* 📉 Time-series analysis of sales
* 🔮 Future sales prediction using historical data trends
* 📊 Interactive zoom and filtering options
